# 프로젝트 주제

전세역전

부동산 공공 실거래가와 위치 정보를 결합한 적정 시세 예측 및 취향 맞춤 매물 추천 서비스

# 주제 선정 이유

집을 구할 때 사람들은 정말 많은 것을 동시에 고민해야 한다.

이 가격이 적절한지, 옵션이나 시설은 어떤지,

주변에 생활 편의 시설이 많은지, 교통편은 괜찮은지..

고민할 것이 많다 보니 집을 구하는 일 자체를 어렵게 느끼고 진입 장벽이 높다고 생각한다.

특히 매물의 호가가 시세보다 비싼지 싼지 알려면 주변 실거래가를 일일이 찾아 비교해야 한다.

그래서 부동산 지식이 없는 사회 초년생이나 첫 자취를 시작하는 사람일수록 정보 비대칭에 노출되기 쉽고,

집을 팔아야만 하는 중개인의 입담에 넘어가 쉽게 계약해 버리는 일이 발생한다.

두번째, 집을 여러 번 구해 본 사람도 자신의 취향은 확고해졌지만 이를 반영할 수단이 없다.

기존 서비스는 "일정 가격 이하", "일정 면적 이상" 같은 단순 필터만 제공한다.

역세권을 우선할지, 층수와 채광을 우선할지, 마트 접근성이나 세탁소 위치를 우선할지 같은

본인도 말로 설명하기 어려운 다양한 조건과 취향을 반영해 주는 서비스는 없다.

그래서 집을 구하러 갈 때 부모님이나 잘 아는 친구를 데려가는 사람들처럼,

만족도 높은 생활을 위해 취향 반영에 최우선순위를 둔 '똑똑한 친구' 같은 사이트를 개발하고자 한다.

기존 서비스가 매물을 단순히 나열하는 데 그친다면,

전세역전은 머신러닝으로 "이 매물이 시세 대비 적절한 가격인지",

"내가 선호하는 기준에 가장 부합하는지"까지 알려준다.

# 주요 기능

**매물 지도 조회 (우선순위 상)**

- 지도 표시 : 수집한 실거래가 매물을 카카오 지도 위에 마커로 표시
- 필터링 : 매물 유형, 거래 유형, 지역, 가격 범위, 방 개수와 면적, 특수 조건 태그로 검색
- 시세 분포 확인 : 가격대별로 마커 색상을 다르게 표시해 지역의 시세 분포를 한눈에 파악
- 실거래가 데이터에는 좌표가 없고 주소만 있어, 지오코딩으로 위도 경도로 변환해 DB에 저장
- 지도를 축소하면 마커를 구역 단위로 묶어 보여줌

**적정 시세 예측 (우선순위 상)**

- 매물의 조건을 입력하면 적정 거래가를 예측하고, 실제 호가와 비교해 저평가 / 적정 / 고평가로 판정
- 거래 유형별 모델 분리 : 매매, 전세, 월세를 각각 따로 학습. 월세는 보증금과 월 임대료를 함께 예측
- 입력 변수 : 전용 면적, 층, 건축년도, 매물 유형, 자치구와 함께 주변 인프라 지표를 사용
- 선형회귀를 기준으로 두고 부스팅 모델과 성능을 비교해 더 나은 쪽을 채택
- 매매 R2 0.86, 전세 R2 0.89 수준의 성능을 확보 (학습 데이터 각각 약 30만 건, 103만 건)
- 저평가로 판정된 매물은 지도에서 강조 색상으로 표시
- 중개인에게는 매물 등록 단계에서 등록가와 AI 예상 시세를 비교해 보여줌

**주변 인프라 분석 (우선순위 상)**

- 각 매물의 교통 편의성과 생활 편의성을 수치로 계산해, 머신러닝 모델의 입력 변수로 변환
- 화면에 직접 노출하기보다 시세 예측과 추천의 재료로 사용
- 교통 : 지하철역, 버스정류소
- 생활 : 대형마트, 편의점, 세탁소
- 교육 : 학교, 학원, 교습소
- 의료 : 병원
- 환경 : 공원 개수와 면적 비율
- 공공데이터로 시설 좌표를 수집한 뒤, 매물 좌표를 기준으로 거리와 개수를 계산해 파생 변수로 저장

**개인 취향 학습 매물 추천 (우선순위 상)**

- 사용자가 매물을 평가하면 그 데이터로 취향 패턴을 학습해, 아직 보지 않은 매물의 예상 호감도를 예측
- 취향 초기 설정 : 최초 로그인 시 1회, 키워드를 고르고 매물 3~4개를 평가해 초기 데이터를 확보
- 평가 기준 : 좋아요 / 그저그럼 / 싫어요 (분석 시 '그저그럼'은 제외)
- 세 갈래의 신호를 100점 만점으로 합산해 매물별 적합도를 계산
- 직접 설정한 취향 57점 : 태그, 매물 유형, 면적, 역세권, 신축, 방 개수, 교육, 공원, 편의시설, 관리비, 병원, 버스
- 행동 이력 33점 : 매물 평가 피드백, 베스트 매물과의 유사도, 관심 매물
- 최근 검색 10점 : 지역, 거래 유형, 가격대, 매물 유형
- 취향 항목을 수정하면 추천 결과에 즉시 반영
- 추천 매물마다 AI 적합도 점수와 추천 이유를 함께 표시

**매물 탐색 및 비교 (우선순위 상)**

- 매물 확인 : 지도 없이 신규 등록순으로 전체 매물을 훑어보는 카드 목록. 3일 이내 등록 매물에는 new 표시
- 매물 상세 : 매물 정보, AI 시세 예측 그래프(최근 4년 시세), 주변환경 태그, 한줄평, 중개사무소 안내를 한 화면에
- 관심 매물 : 하트로 저장한 매물 목록과 최근 본 매물 탭(7일 이내, 최대 10개)
- 매물 비교 : 관심 매물 중 2개를 나란히 비교. 금액, AI 시세, 시세 차이, 면적, 역 거리, 관리비, 주변 환경, AI 추천 점수를 항목별로 보여주고 더 나은 쪽을 강조
- 비로그인 상태에서 문의, 관심 등록, 한줄평을 누르면 로그인 유도

**동네 유형 자동 분류 (우선순위 중)**

- 지역별 특성을 기준으로 비슷한 동네끼리 자동으로 묶어 동네의 성격을 분류
- 교통, 생활, 의료, 교육, 녹지 다섯 개 축의 점수로 서울 행정동 425개를 군집화
- 군집 개수는 3개부터 8개까지 비교해 가장 뚜렷하게 나뉘는 3개를 채택
- 녹지 교통 중심형 : 공원이 압도적으로 많고 교통도 양호한 동네
- 생활편의 의료 중심형 : 마트, 병원, 학원 등 인프라가 고르게 밀집한 도심형 동네
- 조용한 주거형 : 시설 밀도가 낮은 한적한 주거 지역
- 사용자가 취향에 맞는 동네 유형을 먼저 고르고 그 안에서 매물을 찾을 수 있음
- 지도에 군집별 색상으로 구분해 표시

**동네 키워드 분석 (우선순위 중)**

- 사용자가 남긴 한줄평과 매물 설명글에서 자주 언급되는 단어를 뽑아 동네별 키워드를 보여줌
- 수치로는 알 수 없는 동네 분위기(조용함, 주차난, 언덕, 배달 잘됨 등)를 파악할 수 있음
- 형태소 분석으로 명사와 형용사를 추출하고, 불용어를 제거한 뒤 중요도를 계산
- 한줄평 데이터가 없는 초기에는 다른 사이트에서 수집한 데이터로 채움
- 현재 문서 167건을 분석해 행정동 111개의 대표 키워드를 산출
- 동네 상세 페이지에 키워드로 표시하고, 워드클라우드 이미지로도 생성

**동네 탐색 (우선순위 중)**

- 동네 탐색 : 시/구와 동 필터, 태그 탭(분위기 / 생활환경 / 교통 편의 / 자연환경), 인기순 / 매물 많은 순 / 가나다순 정렬
- 동네 상세 : 해당 동을 색으로 채운 지도, 동네 태그, AI 생활 만족도 그래프, 한줄평 키워드, 동네 매물 목록

**매물 등록 및 관리 (우선순위 중)**

- 중개인이 자신의 매물을 등록하고 관리하는 기능
- 6단계 등록 : 기본 정보 → 가격 및 계약 → 사진 → 주변 시설과 옵션 태그 → AI 예상 시세 확인 → 관리자 승인 요청
- 매물 수정 : 등록과 동일한 형식에 기존 값이 채워진 상태. 수정하면 관리자 재승인 필요
- 내 매물 관리 : 전체 / 승인 대기 / 거래 완료 / 관심 등록 요약, 상태별 매물 목록, 조회 추이 그래프, 최근 사용자 문의

**매물 문의 및 중개사무소 추천 (우선순위 중)**

- 마음에 드는 매물을 찾았을 때 실제 거래로 이어질 수 있도록 연결 (계약과 결제는 제공하지 않음)
- 중개인이 등록한 매물이면 해당 중개인에게 바로 문의
- 그 외의 매물이면 주변 중개사무소를 거리순으로 추천
- 중개사무소 안내 : 위치, 이름, 중개사로 검색하고 카드 목록과 지도 마커로 확인
- 중개사무소 상세 : 대표 이미지, 주소와 대표자, 등록번호, 영업시간, 담당 매물, 위치 지도, 이용자 평가, 상담 요청
- 매물을 실제로 확인하고 왔다면 좋아요 / 싫어요를 남길 수 있음

**사용자 역할 구분 (우선순위 중)**

- 회원 가입 시 역할을 구분하고, 역할에 따라 서로 다른 화면과 권한을 제공
- 일반 사용자 : 매물 탐색, 맞춤 추천, 관심 매물과 비교, 동네 탐색, 중개사무소 문의, 한줄평과 신고
- 중개인 : 매물 등록과 수정, AI 시세 확인, 상담과 리뷰 관리, 내 중개사무소 관리
- 관리자 : 회원 관리, 중개인 승인, 매물 승인, 신고 관리, 배치와 모델 모니터링, 공지 작성
- 상단바 메뉴, 접근 가능한 페이지, 조작 버튼을 역할별로 분기

**회원 인증 (우선순위 중)**

- 역할 선택 회원가입 : 일반 사용자와 중개인 중 선택
- 일반 회원가입 : 일반 사용자는 이름, 전화번호, 이메일, 비밀번호 / 중개인은 여기에 공인중개사 등록번호, 중개사무소, 사무실 번호를 추가로 입력
- 소셜 회원가입 : 구글, 카카오, 네이버 최초 로그인 시 부족한 정보를 보완 입력
- 패스워드리스 : 이메일 입력 후 QR을 발급받아 휴대폰으로 등록. 일반 가입한 중개인은 반드시 등록해야 함
- 중개인 자격 인증 : 공인중개사 등록번호와 중개사무소의 사실 여부를 공공 API로 검증
- 본인 인증 : 전화번호 문자 인증, 비밀번호 찾기 이메일 인증

**관리자 콘솔 (우선순위 중)**

- 대시보드 : 총 회원 수, 신규 가입, 정지 회원, 활성 매물, 가입 추이 그래프, 역할 비중 차트
- 회원 관리 : 사용자와 중개인 검색 및 필터
- 중개인 승인 : 중개사무소 정보를 공공 API로 자동 대조해 승인 여부 결정
- 매물 승인 : 등기부등본과 건축물대장, 계약서를 확인. 정보 누락 여부, AI 시세 대비 오차 범위, 매물 정보 일치, 도용 이미지 여부로 판정
- 신고 관리 : 허위 매물과 부적절한 한줄평 신고 처리
- 배치와 모델 모니터링 : 데이터 수집 배치 상태와 모델 성능 지표 확인

**신규 저평가 매물 알림 (우선순위 하)**

- 관심 지역을 등록해 두면 신규 저평가 매물이 등장할 때 알려줌
- 주 1회 정해진 시각에 실거래가 API를 자동 호출
- 마지막 수집 시점을 기록해 같은 데이터를 중복으로 받지 않도록 처리
- 새로 들어온 매물에 시세 예측 모델을 적용해 저평가로 판정되면 알림 발송

**문의, 신고, 공지 (우선순위 하)**

- 문의하기 : 일반 사용자에서 중개인으로 보내는 매물 문의, 관리자로 보내는 서비스 문의(이용 문의 / 버그 신고 / 건의 / 기타)
- 문의 확인 : 보낸 문의와 받은 문의를 역할별 탭으로 구분하고, 답변 대기와 답변 완료를 색상으로 표시
- 신고 : 허위 매물과 부적절한 한줄평을 신고하면 관리자가 처리
- 공지사항 : 목록과 상세 열람. 관리자가 공지를 작성하면 사용자와 중개인에게 알림 발송

**AI 챗봇 및 에이전트 (우선순위 하)**

- 사용자가 자연어로 질문하면 챗봇이 답변하는 기능
- 단순 대화에 그치지 않고 질문의 의도를 파악해 서비스의 기능을 직접 호출하고 결과를 정리해 답함
- "강남역 근처 5억 이하 매물 찾아줘" : 매물 검색 기능 호출
- "이 매물 시세 적정해?" : 적정 시세 예측 모델 호출
- "나한테 맞는 집 추천해줘" : 취향 학습 추천 모델 호출
- "이 동네 분위기 어때?" : 동네 군집 분류와 키워드 분석 호출
- 흩어져 있는 머신러닝 기능을 챗봇 하나로 묶어, 어려운 조작 없이 자연어만으로 서비스 전체를 이용할 수 있게 함

**모델 성능 공개 리포트 (우선순위 하)**

- 서비스가 사용하는 머신러닝 모델의 성능 지표를 사용자에게 공개해 예측 결과의 신뢰도를 보여줌
- 학습에 사용한 데이터 건수, R2, 오차 지표를 함께 표시

# 기대 효과

- 정보 비대칭 완화 : 실거래가 기반의 적정 시세 예측으로, 부동산 지식이 없는 사회 초년생도 호가가 비싼지 싼지 스스로 판단할 수 있음
- 탐색 비용 절감 : 단순 필터를 넘어 개인 취향을 학습해 추천하므로, 여러 조건을 일일이 비교하는 수고를 줄임
- 진입 장벽 완화 : AI 챗봇이 흩어진 기능을 하나로 묶어, 자연어만으로 서비스 전체를 이용할 수 있게 함
- 거래 신뢰성 확보 : 중개인 자격 인증과 매물 서류 검증으로 허위 매물 위험을 낮춤
- 판단 근거 제시 : "왜 이 매물을 추천했는지", "왜 저평가인지"를 함께 보여줘 사용자가 납득하고 결정할 수 있음
- 동네 단위 이해 : 숫자로 드러나지 않는 동네 분위기까지 파악해, 매물만이 아니라 살게 될 생활권을 함께 고려할 수 있음
- 중개인 편의 : 등록 단계에서 AI 예상 시세를 확인할 수 있어, 근거 있는 가격 책정이 가능
