======================================================================
1. Python 3.11.9 설치 확인
======================================================================

PyCharm Terminal 또는 CMD에서 아래 명령어를 입력합니다.

python --version

아래와 같이 나오면 정상입니다.

Python 3.11.9

Python 3.11.9가 설치되어 있지 않은 경우
Python 3.11.9를 먼저 설치합니다.


======================================================================
2. ICT_Final_Project를 PyCharm으로 열고 prentversal 폴더로 이동
======================================================================

PyCharm에서는 prentversal만 별도 프로젝트로 다시 열지 않고
기존 모노레포인 ICT_Final_Project를 그대로 엽니다.

Terminal을 열고 현재 위치가 ICT_Final_Project라면 아래를 입력합니다.

cd prentversal

현재 경로가 아래와 비슷한 형태인지 확인합니다.

D:\ICT_Final_Project\prentversal

PC마다 Clone 위치는 다를 수 있으므로 D: 경로가 아니어도 됩니다.
핵심은 현재 위치가 각자 프로젝트의 prentversal 폴더라는 점입니다.


======================================================================
3. Python 가상환경(.venv) 생성
======================================================================

터미널에서 prentversal 폴더에서 아래 명령어를 실행합니다.

python -m venv .venv

실행 후:

ICT_Final_Project
└─ prentversal
   └─ .venv

가 생성됩니다.

.venv는 각자 PC의 Python 환경이므로 GitHub에 올리지 않습니다.


======================================================================
4. PyCharm Python Interpreter를 .venv에 연결
======================================================================

PyCharm에서 아래 순서로 이동합니다.

Settings
→ Python
→ Interpreter
→ Add Interpreter
→ Add Local Interpreter...

기존 가상환경 사용(Select existing)을 선택하고 아래 Python을 지정합니다.

프로젝트경로\prentversal\.venv\Scripts\python.exe

예시:

D:\ICT_Final_Project\prentversal\.venv\Scripts\python.exe

설정 완료 후 현재 Interpreter가 반드시

prentversal\.venv\Scripts\python.exe

를 사용하고 있는지 확인합니다.

Invalid가 표시되면:

Python Interpreter
→ Show All...
→ 방금 만든 .venv Interpreter 선택
→ 현재 프로젝트와 연결(Associate this virtual environment with the current project)
→ OK

순서로 확인합니다.


======================================================================
5. PyCharm Interpreter Paths에 prentversal 추가 — 중요
======================================================================

이 단계는 PyCharm에서 collectors/training의 .py 파일을 직접 Run했을 때도
기존 import가 정상적으로 동작하도록 만드는 설정입니다.

PyCharm에서:

Settings
→ Python
→ Interpreter
→ " Python Interpreter: " 영역에 드롭다운 버튼
→ Show All...
→ 해당 Interpreter 선택
→ 좌측 상단 파일구조 모양 (Show Interpreter Paths)
→ +
→ 각자 PC의 ICT_Final_Project\prentversal 폴더 추가
→ 추가한 경로 + 우측(added by user) 표시 확인
→ OK / Apply

예시:

D:\ICT_Final_Project\prentversal

다른 팀원의 프로젝트가 C:에 있다면 그 팀원은 자신의 실제 경로를 넣습니다.

예:

C:\Users\사용자명\ICT_Final_Project\prentversal


----------------------------------------------------------------------
왜 이 설정을 하는가 (파이썬의 import의 from을 도커와 맞추기 위해서) (코드가 그렇게 되어있음)
----------------------------------------------------------------------

로컬에서는:

D:\ICT_Final_Project\prentversal    ← Python import 기준점
├─ app
├─ collectors
└─ training

Docker에서는:

/app                                ← Python import 기준점
├─ app
├─ models
├─ data
└─ outputs

처럼 동작합니다.

즉 실제 최상위 폴더 이름을 똑같게 만드는 것이 아니라
"Python이 import를 찾기 시작하는 기준점 아래의 구조"를 맞추는 것입니다.

그래서 코드는 계속:

from collectors.common import ...
from app.config import ...

형식을 사용합니다.

6. PyCharm Terminal에서 가상환경 활성화
======================================================================

PyCharm Interpreter 설정과 Terminal의 가상환경 활성화는 별개입니다.

PyCharm에서:

Settings
→ Tools
→ Terminal
→ Activate virtualenv 체크
→ OK

기존 Terminal을 닫고 새 Terminal을 엽니다.

정상 예시:

(.venv) D:\ICT_Final_Project\prentversal>

자동 활성화가 안 되면 PowerShell:

.\.venv\Scripts\Activate.ps1

CMD:

.venv\Scripts\activate

활성화 후:

python --version

결과가:

Python 3.11.9

인지 다시 확인합니다.

7-3. KoNLPy 실행을 위한 Java 확인 및 환경변수 설정
----------------------------------------------------------------------

KoNLPy의 Komoran 형태소 분석기는 Java(JVM)를 사용하므로
텍스트마이닝을 실행할 PC에서는 Java도 확인합니다.

(자바 경로를 아는 기존의) IntelliJ에서:

File
→ Project Structure...
→ Platform Settings
→ SDKs
→ 현재 사용하는 JDK 선택

JDK home path를 확인합니다.

예:

C:\Users\사용자명\.jdks\ms-21.0.10

JDK 종류, 버전, 설치 경로는 PC마다 다를 수 있으므로
각자 IntelliJ에서 확인한 실제 경로를 사용합니다.


----------------------------------------------------------------------
Windows 환경변수에 JAVA_HOME 추가
----------------------------------------------------------------------

Windows 검색에서:

환경 변수
→ 시스템 환경 변수 편집
→ 환경 변수...

순서로 이동합니다.

위쪽의 사용자 변수에서 새로 만들기를 선택합니다.

변수 이름:

JAVA_HOME

변수 값에는 IntelliJ에서 확인한 JDK home path를 입력합니다.

예:

C:\Users\사용자명\.jdks\ms-21.0.10

JAVA_HOME에는 \bin을 붙이지 않습니다.


그 다음 같은 사용자 변수에 있는 Path를 선택합니다.
Path
→ 편집 (or 변수 이름이 Path인 변수를 더블클릭하거나)
→ 새로 만들기

아래 값을 추가합니다.

%JAVA_HOME%\bin

최종적으로 아래와 같이 설정되어 있으면 됩니다.

(사용자 변수에서)
JAVA_HOME
→ C:\Users\사용자명\.jdks\ms-21.0.10

(사용자 변수인 Path안에서)
Path
→ %JAVA_HOME%\bin

환경변수 설정을 완료한 뒤
열려 있는 환경 변수 창에서 확인을 눌러 저장합니다.

----------------------------------------------------------------------
환경변수 설정 후 PyCharm에서 다시 확인
----------------------------------------------------------------------

환경변수를 변경한 경우 이미 실행 중인 PyCharm에는
변경된 환경변수가 바로 적용되지 않을 수 있습니다.

PyCharm을 완전히 종료한 뒤 다시 실행하고
새 Terminal을 엽니다.

PyCharm Terminal이 CMD인 경우 아래 명령어를 입력합니다.

java -version

where java

echo %JAVA_HOME%


정상 예:

openjdk version "21.0.10"

C:\Users\사용자명\.jdks\ms-21.0.10\bin\java.exe

C:\Users\사용자명\.jdks\ms-21.0.10


PyCharm Terminal이 PowerShell인 경우 아래 명령어를 사용합니다.

java -version

where.exe java

$env:JAVA_HOME


PowerShell에서는 JAVA_HOME을 확인할 때

echo %JAVA_HOME%

이 아니라

$env:JAVA_HOME

을 사용합니다.


java -version이 정상적으로 실행되고
Java 실행 파일의 위치와 JAVA_HOME이 현재 사용하는 JDK를 가리키면
KoNLPy를 실행하기 위한 Java 설정이 완료된 것입니다.

Java 환경변수 설정은 해당 PC에서 처음 세팅할 때 한 번만 하면 됩니다.

Python 가상환경(.venv)과 Java는 별개의 환경이므로
.venv를 활성화할 때마다 Java를 다시 설정할 필요는 없습니다.

8. .env 파일 생성
======================================================================

.env에는 실제 API Key 등의 비밀정보가 들어가므로 Git에서 제외되어 있습니다.

prentversal\.env.example을 복사해서
같은 위치에 .env를 만듭니다.

prentversal
├─ .env
└─ .env.example

.env.example에 있는 환경변수 이름은 임의로 바꾸지 않고
.env에 각자 사용할 실제 값을 넣습니다.

실제 API Key는 GitHub에 Commit/Push하지 않습니다.

======================================================================
9. FastAPI 서버 실행 확인
======================================================================

최종 FastAPI의 app\main.py는 FastAPI 객체를 정의하고
uvicorn이 그 객체를 불러와 서버를 실행하는 구조입니다.

따라서 최종 구현 후에는 app\main.py를 단순 Python 파일처럼 직접 Run하는 방식보다
아래 uvicorn 실행을 기준으로 합니다.

현재 위치:

(.venv) D:\ICT_Final_Project\prentversal>

실행:

uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

정상 주소:

http://127.0.0.1:8000

Swagger:

http://127.0.0.1:8000/docs

Health:

http://127.0.0.1:8000/health
