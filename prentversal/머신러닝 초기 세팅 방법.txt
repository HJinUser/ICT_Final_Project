======================================================================
Rentversal Python / 머신러닝 초기 세팅 방법
======================================================================

GitHub에서 ICT_Final_Project를 처음 Clone하거나 Pull 받은 뒤
prentversal Python/FastAPI 프로젝트를 실행하기 위한 초기 세팅 방법입니다.

Python 버전은 3.11.9를 사용합니다.

.venv와 .env 파일은 Git에서 제외되어 있으므로
해당 파일이 없는 경우 아래 순서대로 직접 생성 및 설정해야 합니다.


======================================================================
1. Python 3.11.9 설치 확인
======================================================================

PyCharm 터미널 또는 CMD에서 아래 명령어를 입력합니다.

python --version


아래와 같이 나오면 정상입니다.

Python 3.11.9


Python 3.11.9가 설치되어 있지 않은 경우
Python 3.11.9를 먼저 설치합니다.


======================================================================
2. prentversal 폴더로 이동
======================================================================

PyCharm에서 ICT_Final_Project 프로젝트를 연 뒤
Terminal을 실행합니다.

현재 위치가 ICT_Final_Project라면 아래 명령어를 입력합니다.

cd prentversal


현재 경로가 아래와 비슷한 형태인지 확인합니다.

D:\ICT_Final_Project\prentversal


======================================================================
3. Python 가상환경(.venv) 생성
======================================================================

.venv는 각자의 PC에서 사용하는 Python 가상환경입니다.

GitHub에서 프로젝트를 처음 받은 경우 .venv가 없으므로
prentversal 폴더에서 아래 명령어를 실행합니다.

python -m venv .venv


실행 후 아래와 같이 .venv 폴더가 생성됩니다.

ICT_Final_Project
└─ prentversal
   └─ .venv


아직 PyCharm에서 이 가상환경을 사용하도록 설정한 것은 아니므로
다음 단계에서 Interpreter 설정을 진행합니다.


======================================================================
4. PyCharm Python Interpreter 설정
======================================================================

이 설정은 PyCharm에서 Python 파일을 우클릭하여 Run했을 때
방금 생성한 .venv의 Python을 사용하도록 설정하는 과정입니다.


PyCharm에서 아래 순서로 이동합니다.

Settings
→ Python
→ Interpreter
→ Add Interpreter
→ Add Local Interpreter...


Select existing을 선택합니다.


Python 경로에는 아래 파일을 선택합니다.

프로젝트경로\prentversal\.venv\Scripts\python.exe


예시)

D:\ICT_Final_Project\prentversal\.venv\Scripts\python.exe


선택 후 OK를 누릅니다.


만약 Python Interpreter에 Invalid가 표시되거나
가상환경이 프로젝트와 정상적으로 연결되지 않은 경우에는

Python Interpreter의 아래쪽 화살표(↓)
→ Show All...
→ 방금 만든 .venv Interpreter 선택
→ Associate this virtual environment with the current project 체크
→ OK

순서로 설정합니다.


설정이 완료되면 PyCharm의 Python Interpreter가

prentversal\.venv\Scripts\python.exe

를 사용하고 있는지 확인합니다.


이 설정이 정상적으로 되어 있으면

app\main.py 우클릭
→ Run 'main'

으로 실행했을 때 .venv의 Python으로 실행됩니다.


======================================================================
5. PyCharm Terminal에서 가상환경 자동 활성화 설정
======================================================================

Python Interpreter 설정과
PyCharm Terminal의 가상환경 활성화는 별개의 설정입니다.

PyCharm에서 아래 순서로 이동합니다.

Settings
→ Tools
→ Terminal

가장 아래쪽에 있는

Activate virtualenv

항목을 체크한 뒤 OK를 누릅니다.


기존에 열려 있던 Terminal이 있다면 닫고
새 Terminal을 엽니다.


Terminal 앞부분에 아래와 같이 (.venv)가 표시되는지 확인합니다.

(.venv) D:\ICT_Final_Project\prentversal>


(.venv)가 표시되어 있으면
현재 Terminal도 가상환경을 정상적으로 사용하고 있는 상태입니다.


만약 자동으로 활성화되지 않는 경우
PowerShell에서는 아래 명령어를 실행합니다.

.\.venv\Scripts\Activate.ps1


CMD에서는 아래 명령어를 실행합니다.

.venv\Scripts\activate


활성화 후 아래 명령어로 Python 버전을 다시 확인합니다.

python --version


아래와 같이 나오면 정상입니다.

Python 3.11.9


======================================================================
6. 필요한 Python 라이브러리 설치
======================================================================

반드시 Terminal 앞에 (.venv)가 표시된 상태에서 진행합니다.

또한 현재 위치가 requirements.txt가 있는
prentversal 폴더인지 확인합니다.


----------------------------------------------------------------------
6-1. FastAPI 서버 실행에 필요한 기본 라이브러리 설치
----------------------------------------------------------------------

아래 명령어를 실행합니다.

pip install -r requirements.txt


requirements.txt에 프로젝트에서 사용하는 기본 라이브러리와
버전이 작성되어 있으므로

pip install fastapi
pip install uvicorn

처럼 각각 따로 설치할 필요가 없습니다.


----------------------------------------------------------------------
6-2. 머신러닝 관련 작업까지 하는 경우
----------------------------------------------------------------------

머신러닝, 데이터 수집, 데이터 전처리, 모델 학습,
텍스트마이닝 등의 작업까지 하는 경우 아래 명령어를 실행합니다.

pip install -r requirements-ml.txt


requirements-ml.txt에는 머신러닝 작업에 필요한
추가 라이브러리가 작성되어 있습니다.


======================================================================
7. .env 파일 생성
======================================================================

.env에는 실제 API Key 등의 비밀정보가 들어가기 때문에
Git에서 제외되어 있습니다.

따라서 GitHub에서 프로젝트를 처음 받은 경우
.env 파일이 존재하지 않습니다.


prentversal 폴더에 있는

.env.example

파일을 복사한 뒤 파일 이름을

.env

로 변경합니다.


최종적으로 아래 두 파일이 존재하면 됩니다.

prentversal
├─ .env
└─ .env.example


.env.example에 작성되어 있는 환경변수 이름을 확인한 뒤
.env 파일에 자신이 사용할 실제 API Key 값을 입력합니다.


.env.example에 작성된 환경변수 이름은 임의로 변경하지 않습니다.


======================================================================
8. FastAPI 서버 실행 확인
======================================================================

서버 실행 전에 아래 내용을 확인합니다.


1) PyCharm Python Interpreter가

prentversal\.venv\Scripts\python.exe

로 설정되어 있는지 확인


2) PyCharm Terminal을 사용하는 경우

(.venv)

가 표시되어 있는지 확인


----------------------------------------------------------------------
8-1. PyCharm Run으로 실행
----------------------------------------------------------------------

app\main.py 파일을 우클릭한 뒤

Run 'main'

을 선택합니다.


4단계에서 Python Interpreter 설정을 정상적으로 했다면
.venv의 Python을 이용해서 실행됩니다.


----------------------------------------------------------------------
8-2. PyCharm Terminal에서 실행
----------------------------------------------------------------------

현재 위치가 prentversal인지 확인합니다.

예시)

(.venv) D:\ICT_Final_Project\prentversal>


아래 명령어를 실행합니다.

uvicorn app.main:app --reload


정상적으로 실행되면 기본적으로 아래 주소에서 실행됩니다.

http://127.0.0.1:8000


FastAPI Swagger 문서는 아래 주소에서 확인할 수 있습니다.

http://127.0.0.1:8000/docs


======================================================================
9. 최초 세팅 이후
======================================================================

위의 초기 세팅은 해당 PC에서 처음 프로젝트를 설정할 때
한 번만 진행하면 됩니다.


한 번 생성한 .venv가 정상적으로 남아 있다면

- .venv를 다시 생성할 필요 없음
- PyCharm Interpreter를 다시 연결할 필요 없음
- 라이브러리를 매번 다시 설치할 필요 없음


PyCharm을 다시 실행한 경우에는

1. Python Interpreter가 기존 .venv로 설정되어 있는지 확인

2. Terminal을 사용할 경우 (.venv)가 표시되어 있는지 확인

한 뒤 작업하면 됩니다.


FastAPI 서버를 Terminal에서 실행할 경우)

uvicorn app.main:app --reload


======================================================================
10. requirements 파일이 변경된 경우
======================================================================

다른 팀원이 새로운 Python 라이브러리를 추가하여

requirements.txt

또는

requirements-ml.txt

가 변경된 경우에는 Git Pull 후 변경된 requirements 파일을
이용해서 필요한 라이브러리를 다시 설치합니다.


기본 라이브러리)

pip install -r requirements.txt


머신러닝 관련 라이브러리)

pip install -r requirements-ml.txt
