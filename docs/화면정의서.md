# 화면 정의서

부동산 매물 플랫폼 화면 설계 문서

---

## 0. 문서 읽는 법

- **공통 → 역할별 추가** 구조로 작성했습니다. 각 페이지는 `공통(비로그인 기준)` 항목을 먼저 읽고, 자기 역할 섹션에서 **추가/변경되는 것만** 확인하면 됩니다.
- 역할은 4가지입니다: `비로그인` / `사용자` / `중개인` / `관리자`
- 아직 결정되지 않은 항목은 본문에 `⚠️` 로 표시하고, [7. 미확정 사항](#7-미확정-사항-결정-필요)에 모아두었습니다.

|---|--------|------|
| 1 | 상단바 (공통 컴포넌트) | 모든 페이지 상단 고정 |

| 8 | 중개사무소 안내 / 매물 등록 / 매물 관리 | 상세 정의 필요 |

## 1. 상단바 (공통 컴포넌트)

모든 페이지 상단에 고정. **좌측 = 이동 메뉴**, **우측 = 검색 및 계정**.

### 1-1. 좌측 영역

| 요소 | 노출 조건 | 동작 |
|------|-----------|------|
| **로고** | 항상 | **호버**: "전세" 글자가 천천히 회전하며 좌우 반전<br>**클릭**: 메인 홈페이지로 이동 |
| **지도 검색** | 항상 | 클릭 → `지도 검색` 페이지 |
| **동네 탐색** | 항상 | 클릭 → `동네 탐색` 페이지 |
| **중개사무소 안내** | 사용자 | 클릭 → `중개사무소 안내` 페이지 |
| **매물 등록** | 중개인 | 클릭 → `매물 등록` 페이지 |
| **매물 관리** | 관리자 | 클릭 → `매물 관리` 페이지 |

> 마지막 3개는 같은 자리에서 **role에 따라 하나만** 노출됩니다.

### 1-2. 우측 영역

| 요소 | 노출 조건 | 동작 |
|------|-----------|------|
| **소형 검색창** | 항상 | placeholder: "지역명 검색" ⚠️(문구 확정 필요)<br>**클릭**: placeholder 제거, 입력 가능 상태<br>**검색어 입력**: `매물 검색` 페이지로 이동 |
| **로그인** | 비로그인 | 클릭 → `로그인` 페이지 |
| **회원가입** | 비로그인 | 클릭 → `회원가입` 페이지 |
| **알림** | 로그인(전체) | 클릭 → 드롭다운 리스트로 펼쳐짐, **최근 5개**까지 표시 |
| **내 정보** | 로그인(전체) | 이름/닉네임 **첫 글자 원형 텍스트 프로필 아이콘** + 우측에 이름(닉네임) 노출<br>클릭 → `마이페이지` |
| **로그아웃** | 로그인(전체) | 클릭 → 로그아웃 처리 후 메인 홈페이지로 이동 |

## 2. 메인 홈페이지

### 2-1. 공통 (비로그인 · 사용자)

> **설계 원칙**: 매물 사진 등 시각 요소로 시세 현황을 비교하고 결정하도록 유도

| 요소 | 상세 |
|------|------|
| **큰 검색창** | 비로그인 placeholder: "원하는 지역을 입력하세요"<br>사용자 placeholder: "원하는 지역, 지하철 등을 입력해주세요"<br>**클릭**: placeholder 제거, 입력 가능 상태<br>**입력 후 검색**: 비로그인 → `지도 검색` / 사용자 → `매물 검색` ⚠️(이동 페이지가 서로 다른 게 의도인지 확인 필요) |
| **거래 유형 바로가기** | `전세 / 월세 / 매매` 콤보 형식 ⚠️(콤보박스 vs 버튼 확정 필요)<br>선택한 유형 클릭 → 해당 유형이 필터링된 `지도 검색` 페이지로 이동 |
| **동네 탐색 영역** | 인기순 정렬된 동네를 **3개 추천**, 작은 카드 3개로 노출<br>클릭 → `동네 탐색` 페이지 |

**사용자 로그인 시 추가로 유도할 행동** (배치 위치 ⚠️ 미정)
찜하기 · 문의하기 · 방문예약 · 매물 신고 · 최근 본 매물 동기화 · 맞춤추천 설정 · 중개사 채팅 문의

### 2-2. 중개인

**중개인 대시보드** — 수치 카드 형태로 노출

| 지표 |
|------|
| 등록 매물 수 |
| 승인 대기 매물 수 |
| 노출 중인 총 매물 수 |
| 거래 완료 매물 수 |

### 2-3. 관리자

**관리자 대시보드** — 통계 수치 카드, 2행 3열 배치

| 1행 | 총 회원 수 | 신규 가입 수 | 중개인 승인 대기 |
|-----|-----------|-------------|-----------------|
| **2행** | **매물 승인 대기** | **신고 접수 수** | **문의 접수 수** |

## 3. 지도 검색 페이지

**3단 레이아웃**: `왼쪽 사이드바(필터)` + `중앙(지도)` + `오른쪽 사이드바(매물 리스트)`

### 3-1. 공통 (모든 역할)

#### 왼쪽 사이드바 — 제목: "필터"

| 필터 | 상세 |
|------|------|
| **지역 선택** | 셀렉트 박스로 지역 선택<br>⚠️ 서울 외 지역까지 지원할 경우: 상단에 `서울 / 경기 …` 라디오 버튼을 두고, 선택에 따라 하위 셀렉트 박스 항목이 변경 |
| **거래 유형** | `[전체] [매매] [월세] [전세]` 버튼<br>클릭 시 지도에 해당 유형 매물만 필터링<br>**기본값: 전체** |
| **가격 범위** | `최소 금액` ~ `최대 금액` 입력창<br>하단에 자주 검색되는 가격대 버튼 노출 (거래 유형에 따라 버튼 구성이 달라짐) ⚠️(구간 값 확정 필요)<br>**기본값: 0 ~ 무제한 (전체 노출)** |
| **방 개수** | `[전체] [1개(원룸)] [2개] [3개] [4개 이상]`<br>개별 항목 선택 시 `전체` 해제<br>**복수 선택 가능** — 선택한 종류를 모두 포함해 노출<br>**기본값: 전체** |
| **면적** | `최소 면적` ~ `최대 면적` 셀렉트 박스 ⚠️(구간 기준값 확정 필요) |
| **태그 검색** | 많이 찾는 태그 **5개**를 버튼으로 노출 |
| **조건 적용 버튼** | 클릭 시 위 조건을 모두 적용해 매물 필터링 |

#### 중앙 — 지도

- 카카오 지도 API 연동

#### 오른쪽 사이드바 — 제목: "매물 리스트"

| 요소 | 상세 |
|------|------|
| **정렬 기준** | 드롭다운 메뉴<br>· 최신 등록순 **(기본값)**<br>· 가격 낮은순 / 가격 높은순<br>· 면적 넓은순 / 면적 좁은순 |
| **매물 카드 리스트** | 위 → 아래 세로 정렬<br>화면에 **4개**가 보이도록 구성<br>카드 클릭 → `매물 상세` 페이지 |

### 3-2. 사용자 (공통 대비 변경점)

| 영역 | 변경 내용 |
|------|-----------|
| 왼쪽 사이드바 · 태그 검색 | 많이 본 태그 **2~3개** + 로그인 사용자가 많이 찾은 태그 **5개**를 버튼으로 노출 ⚠️(두 그룹을 어떻게 구분해 보여줄지 확정 필요) |

### 3-3. 중개인 (공통 대비 변경점)

| 영역 | 변경 내용 |
|------|-----------|
| 왼쪽 사이드바 | **"내가 등록한 매물" 버튼** 추가 — 클릭 시 오른쪽 리스트에 본인 등록 매물만 노출 |
| 중앙 지도 | 본인이 등록한 매물 핀을 **다른 핀과 시각적으로 구분** |
| 오른쪽 사이드바 | **`전체` / `내 매물` 탭** 추가<br>· 전체: 구분 없이 전체 노출<br>· 내 매물: 본인 등록 매물만 노출 |

### 3-4. 관리자 (공통 대비 변경점)

| 영역 | 변경 내용 |
|------|-----------|
| 중앙 지도 | **일반 핀 / 신고 핀 구분**<br>· 일반 핀: 일반 매물<br>· 신고 핀: 사용자가 신고한 매물 |
| 오른쪽 사이드바 | **`전체` / `신고` 탭** 추가<br>· 전체: 구분 없이 전체 노출<br>· 신고: 신고된 매물만 노출 |
| 매물 카드 | 카드 내 조작 버튼 추가<br>· **숨김 버튼** — 클릭 시 해당 매물이 사용자에게 노출되지 않음<br>· **신고 확인 버튼** — ⚠️ 클릭 시 동작 미정 |

## 4. 페이지 이동 흐름 요약

```
상단바(전역)
 ├─ 로고 ─────────────→ 메인 홈페이지
 ├─ 지도 검색 ────────→ 지도 검색
 ├─ 동네 탐색 ────────→ 동네 탐색
 ├─ [role] ───────────→ 중개사무소 안내 / 매물 등록 / 매물 관리
 ├─ 소형 검색창 ──────→ 매물 검색
 ├─ 로그인·회원가입 ──→ 로그인 / 회원가입
 └─ 내 정보 ──────────→ 마이페이지

메인 홈페이지
 ├─ 큰 검색창 ────────→ 지도 검색(비로그인) / 매물 검색(사용자)
 ├─ 거래 유형 선택 ───→ 지도 검색 (유형 필터 적용)
 └─ 동네 카드 3개 ────→ 동네 탐색

지도 검색
 └─ 매물 카드 ────────→ 매물 상세
```

## 6. 추가 아이디어 (초안 · 정리 필요)

원문 후반부에 있던 메모입니다. 위 본문과 중복되는 부분이 있어 **아직 반영하지 않은 항목만** 남겼습니다.

- 메인 페이지 영역 구성안: 상단 검색 영역 / 지도 검색 영역 / 추천 매물 영역 / 매물 유형 바로가기 / 회원 메뉴 / 중개사 매물 등록
- **검색 시작 영역**: 지역명 · 역세권 · 단지별 검색
- **빠른 탐색**: 지도에서 찾기 · 내 주변 매물 · 최근 본 매물 · 인기 지역
- **추천 매물**: 신규 매물 · 인기 매물 · 가격 인하 매물 · 지역별 추천 매물
- **정보 영역**: 내용 미정
- 거래 유형 선택 UI를 **콤보 박스로 중앙 배치**

> ⚠️ 이 항목들은 [2. 메인 홈페이지](#2-메인-홈페이지)에 흡수할지, 별도 섹션으로 둘지 결정 필요합니다.

## 7. 미확정 사항 (결정 필요)

| # | 항목 | 위치 | 내용 |
|---|------|------|------|
| 1 | 상단 검색창 placeholder 문구 | 1-2 | "지역명 검색"은 임시 문구 |
| 2 | 큰 검색창의 이동 페이지 | 2-1 | 비로그인은 `지도 검색`, 사용자는 `매물 검색`으로 다르게 적혀 있음 — 의도된 차이인지 확인 |
| 3 | 거래 유형 UI 형식 | 2-1 | 콤보박스 / 버튼 / 탭 중 확정 |
| 4 | 사용자 행동 유도 요소 배치 | 2-1 | 찜·문의·방문예약 등을 메인 어디에 노출할지 |
| 5 | 가격 범위 프리셋 구간 | 3-1 | 거래 유형별 기본 가격대 버튼 값 |
| 6 | 면적 셀렉트 박스 구간 기준 | 3-1 | 최소/최대 면적 선택 항목 값 |
| 7 | 사용자 태그 노출 방식 | 3-2 | "많이 본 태그 2~3개"와 "많이 찾은 태그 5개"의 구분 및 배치 |
| 8 | 신고 확인 버튼 동작 | 3-4 | 클릭 시 처리 로직 미기재 |
| 9 | 지역 범위 | 3-1 | 서울 한정인지, 전국 확장인지 |
| 10 | 미정의 페이지 상세 | 0 | 동네 탐색 / 매물 검색 / 매물 상세 / 로그인 / 회원가입 / 마이페이지 / 중개사무소 안내 / 매물 등록 / 매물 관리 |
