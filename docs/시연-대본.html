촬영 순서 ≠ 편집 순서

계정 전환을 줄이려면 관리자 → 중개인 → 사용자 순서로 찍고 편집에서 재배열한다. 사용자 씬을 마지막에 찍어야 앞 단계에서 만든 데이터가 화면에 반영돼 있다. 관리자 촬영 때는 승인 대기 매물을 일부 남겨 둘 것.

다만 매물 등록 → 관리자 승인 → 사용자에게 노출을 한 흐름으로 보여 주고 싶다면 예외적으로 순서대로 찍는다. 이 경우 계정 전환 3회가 생기므로 전환 장면은 역할 카드 자막으로 덮는다.
