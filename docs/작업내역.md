# 작업 내역 (김주연)

전세역전 - 부동산 공공 실거래가 기반 시세 예측 및 취향 맞춤 매물 추천 서비스

> 커밋 이력(2026-07-24 ~ 2026-08-20) 기준으로 담당한 작업을 영역별로 정리했습니다.

---

## 1. 서비스 기획 · 설계

- 부동산 웹 서비스 전체 페이지 구성 및 사용자 역할별(비로그인 / 사용자 / 중개인 / 관리자) 기능·화면 흐름 기획 및 화면정의서 작성
- 상단바·메인 홈·지도 검색·동네 탐색·매물 상세·중개사무소 등 화면별 노출 조건과 역할별 분기 규칙 정의
- ERD 및 도메인 테이블 설계 문서화(ERD.md / ERD.svg / ERD.png)
- 초기 데이터(data.sql) 구성 및 엔티티 테이블명 표기 규칙(복수형) 통일

## 2. 공인중개사무소(Agency) 도메인

- 공인중개사 사무소 목록 조회·등록·수정 및 페이지네이션·정렬 기능 구현
- 키워드 / 자치구 / 행정동 조건 기반 중개사무소 검색 기능 구현
- 중개사무소 상세(사무소 정보, 소속 매물 목록, 리뷰, 상담) 조회 API 및 화면 구현
- 멀티파트 이미지 처리 및 공인중개사무소 사진 등록·갱신 기능 구현
- 카카오 지오코딩을 활용한 주소 기반 위·경도 자동 변환 및 갱신 기능 구현
- 중개사무소 리뷰 등록·조회·평점 집계 및 중개인 답변 기능 구현
- 중개사무소 상담(문의) 등록·답변 및 상담 상태(대기 / 답변완료 / 종료) 관리 로직 구현
- 사용자 문의 내역 조회 화면 및 API 구현
- 카카오 지도 기반 중개사무소 위치 표시 컴포넌트 구현
- 공인중개사무소 관련 페이지 구현 및 백엔드 기능 연동

## 3. 중개인 전용 기능

- 중개인 전용 화면(내 중개사무소, 문의 답변, 중개사 인증 신청) 설계 및 구현
- 내 중개사무소 대시보드(보유 매물 수, 상담·리뷰 현황) API 및 화면 구현
- 내 매물 카드 목록 페이지네이션 및 상태별 조회 기능 구현
- 중개인 문의 답변 / 리뷰 답변 처리 기능 구현
- 중개사 자격 인증 신청 및 심사 상태 조회 기능 구현
- 중개사무소 정보 수정 시 주소 변경분에 대한 좌표 재계산 연동

## 4. 관리자 기능

- 관리자 공인중개사무소 인증 승인 상태(PENDING) 관리 로직 구현
- 관리자 중개인 인증 승인·반려 처리 및 대기 건수 집계 기능 구현
- 관리자 매물 승인·반려 및 가격 평가 상태 관리 기능 구현
- 관리자 콘솔 탭 구조 및 관리자 홈 패널 화면 구현
- 관리자 동네(행정동) 등록·관리 페이지 및 API 구현

## 5. 알림(Notification) 도메인

- 알림 도메인 설계 및 구현 (상담 요청 / 상담 답변 / 리뷰 / 매물 승인 / 중개인 인증 / 공지)
- 사용자·중개인·관리자 역할별 알림 생성·조회·읽음 처리 기능 구현
- 상단바 알림 드롭다운(최근 5건) 연동 및 알림 유형별 이동 경로 처리

## 6. 매물 · 지도 검색

- 지도 검색 페이지 구현 및 백엔드 기능 연동
- 매물 검색 조건 DTO 및 동적 쿼리 구현(매물 유형, 거래 유형, 지역, 가격 범위, 방 개수, 면적, 태그)
- 카카오 지도 마커 표시 및 마커 클릭 시 해당 매물만 필터링하는 상호작용 구현
- 지도 범위(bounds) 기반 매물 조회 및 자치구·행정동 경계 폴리곤 표시 기능 구현
- 자치구 / 행정동 드롭다운과 지도 이동·확대 연동 처리
- 중개인 본인 매물 마커 구분 표시 기능 구현
- 매물 등록·수정 폼의 주소 입력(다음 우편번호) 컴포넌트 및 지오코딩 연동 구현
- 매물 미리보기 화면 및 썸네일 처리 보완
- 메인 홈페이지 시세 반영 추천 영역 및 동네 추천 영역 구현

## 7. 회원 · 공통 기반

- JWT 토큰 검증 및 시큐리티 설정 보완, 역할별 API 접근 권한 정리
- 회원가입 이용약관 동의 컴포넌트 및 약관 페이지 구현
- 마이페이지 화면 구현
- 전체 라우팅 구성 및 역할별 상단바 메뉴 / 하단 네비게이션바 구현
- 공통 스타일 및 반응형 CSS 구성

## 8. 머신러닝 기반 맞춤 추천

- 시세 예측·동네 군집화 결과와 사용자 선호 정보를 활용한 머신러닝 기반 취향 예측 모델 구현
- FastAPI 맞춤 추천 API(`/ml/recommendation/recommend`) 및 요청·응답 스키마 설계
- 직접 설정 취향 57점 + 행동 이력 33점 + 최근 검색 10점의 100점 만점 적합도 스코어링 로직 설계 및 구현
  - 직접 취향: 매물 유형, 면적, 방 개수, 신축, 역세권, 교육, 공원, 병원, 편의시설, 버스, 관리비, 태그
  - 행동 이력: 매물 평가 피드백, 베스트 매물 유사도, 관심 매물
  - 최근 검색: 지역, 거래 유형, 가격대, 매물 유형
- 예산 범위 이탈 매물에 대한 감점 처리(후보 제거 대신 감점) 및 점수 정규화 로직 구현
- 동네 군집·행정동 특성 데이터를 활용한 추천 동네 산출 로직 구현
- Spring 추천 API 및 권한 연결, 취향 저장 / 피드백 / 베스트 매물 / 최근 검색 저장 기능 구현
- React 맞춤 추천 및 최근 검색 연동, 추천 매물·추천 동네 카드 화면 연결
- 추천 핵심 규칙(범위 점수, 예산 감점) 자동 테스트(pytest) 작성
